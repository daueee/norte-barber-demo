# Norte Barber — demo website

Editorial black-and-white one-page site for a fictional barbershop, built as a portfolio sample.

- Pure HTML/CSS, no frameworks — fast and easy to host
- Split-screen hero, full-screen menu, service price list, gallery, booking form
- Fully responsive (desktop / tablet / phone)
- WhatsApp booking link; form is demo-only (client versions post to an n8n webhook → WhatsApp/email/CRM)

Photos: [Unsplash](https://unsplash.com) (free license), shown in grayscale.
